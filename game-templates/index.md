# Game templates

A new Mango Shark game starts from the same two things: the **Game Template asset** in Studio, and the same
**docs layout** here.

| Template | Use it to | Page |
| --- | --- | --- |
| Game Template asset (`GameTemplate.rbxm`) | Set up a new place with the shared framework: module loader, packets, player data, effects, settings, combat | [Game Template asset](game-template.md) |
| New game docs | Start the new game's folder on this site, with the pages every game keeps | [New game docs](new-game-docs.md) |

The template was taken from Gun Game (SiegeBlox) on 2026-11-27. Gun Game is still the source of truth for this code:
when a template module is improved there, save the template again (see
[Updating the template](game-template.md#updating-the-template)).
